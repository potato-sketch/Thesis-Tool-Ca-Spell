# CalamanCy (https://github.com/ljvmiranda921/calamanCy): Tagalog NLP pipelines for spaCy.
# preprocessing/pipeline.py loads the tl_calamancy_md model with calamancy.load().
#
# Install this file WITHOUT dependencies, after requirements.txt:
#     python -m pip install --no-deps -r requirements-calamancy.txt
# (`npm start` / `npm run setup` do this automatically.)
#
# Why: calamancy 0.2.3 declares spacy-transformers<=1.3.5 as a dependency, which pulls in
# transformers 4.36, tokenizers 0.15 and PyTorch (several GB) and does not install on
# Python 3.13+. Those are only needed by the transformer model (tl_calamancy_trf); calamancy's
# own code never imports them, and the md model used here runs on plain spaCy. The packages
# calamancy does import (spacy, huggingface_hub, wasabi) are installed by requirements.txt.
# `pip check` will report "calamancy requires spacy-transformers"; that is expected.
calamancy==0.2.3
